# Team Responsibilities

## Member 1: Frontend Development

- Set up React application
- Create page layouts
- Build registration and login pages
- Build user dashboard
- Build donor profile page
- Build blood request form
- Build donor request cards
- Build LifeToken wallet page
- Build responsive user interface
- Integrate frontend with backend APIs

## Member 2: Backend Development

- Set up Express server
- Configure MongoDB connection
- Build authentication APIs
- Implement JWT authentication middleware
- Build user profile APIs
- Build blood request APIs
- Build donor response APIs
- Build error handling middleware
- Add input validation

## Member 3: Database and Matching Logic

- Design MongoDB collections
- Create Mongoose models
- Implement donor matching logic
- Implement blood group and location filters
- Create BloodBank model
- Create RemoteDonationAssignment model
- Implement LifeToken transaction logic
- Implement community-tier calculation
- Prevent duplicate donor responses and duplicate token awards

## Member 4: Admin, Partner, Testing, and Deployment

- Build admin dashboard
- Build blood-bank partner dashboard
- Build request verification feature
- Build donation verification feature
- Build remote donation assignment feature
- Track remote donation coordination status
- Test all APIs using Postman
- Deploy frontend and backend
- Maintain README and project documentation
- Prepare PPT, screenshots, and demo video
