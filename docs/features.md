# Features

## User features

- User registration and login
- Secure password storage
- JWT-based authentication
- One user account can act as donor and requester
- User profile management
- Blood group and location management
- Donor availability toggle
- Donation history view
- LifeToken wallet view
- Community tier and badge view

## Blood request features

- Create a blood request for self, family, or friend
- Specify blood group and required blood component
- Specify required units
- Add hospital and location details
- Select request urgency
- Add required date and time
- Track request status
- Cancel or close a request
- Upload supporting document, optional for the first version

## Donor coordination features

- Match donors using blood group and location
- Display active verified requests to suitable donors
- Allow donors to respond to blood requests
- Prevent duplicate donor responses
- Show donor responses to the requester
- Use controlled contact sharing
- Show request urgency and hospital information
- Allow donors to set availability as available or unavailable

## Remote donation and transfer coordination

- Suggest a nearby verified blood-bank partner for a compatible donor
- Reduce donor travel burden when the donor is far from the recipient hospital
- Allow donors to accept or decline a suggested donation centre
- Allow donors to select an appointment time, optional for the first version
- Track donation centre assignment status
- Track donation appointment status
- Allow blood-bank partners or administrators to verify donation
- Track blood-bank coordination status for the recipient request
- Award LifeTokens only after a donation is verified
- Display a safety disclaimer that blood collection, testing, storage, cold-chain handling, and transfer are managed only by authorized blood banks

## LifeToken features

- Award tokens for verified community contributions
- Award tokens for complete donor profile
- Award tokens for phone verification
- Award tokens for verified blood donation
- Award tokens for verified donation-camp participation
- Record all token transactions
- Display token balance
- Display donation history
- Award community badges
- Calculate community tier
- Provide non-monetary recognition and platform-level coordination support
- Never provide cash payment, guaranteed blood, or medical priority through tokens

## Admin features

- Verify or reject blood requests
- Verify donation records
- Manage users
- Review suspicious requests
- View token transactions
- Close or expire requests
- Manage partner blood-bank records
- Assign donors to nearby verified blood banks
- Update remote donation coordination status

## Blood bank partner features

- View assigned remote donation cases
- View donor appointment information
- Verify completed donations
- Update donation verification status
- Update coordination status
- View basic request information needed for coordination

## Safety and privacy features

- Role-based access control
- Backend input validation
- Password hashing
- Protected API routes
- Controlled exposure of contact information
- Request expiry
- Report suspicious activity
- Admin verification for requests
- Admin or blood-bank verification for donations
- No direct donor-to-patient blood transport
- Blood collection and transfer only through authorized blood banks
