
# LifeLink — Blood Donor Coordination Platform

LifeLink is a full-stack web application that connects voluntary blood donors with verified blood requests. The platform supports donor-requester coordination, blood request verification, donor availability, remote donation coordination, and a non-monetary LifeToken recognition system for verified community contributions.

## Problem addressed

During blood emergencies, patients and their families may struggle to find compatible voluntary donors quickly. LifeLink provides a structured workflow for request creation, request verification, donor matching, donor responses, and coordination with verified blood-bank partners.

## Key innovation

A single user can act as both a donor and a requester.

If a compatible donor is far from the recipient hospital, LifeLink can suggest a nearby verified blood-bank partner or donation centre. The donor can donate at that authorized centre, while the blood bank manages donor screening, collection, testing, storage, cold-chain handling, and any approved coordination with the recipient hospital or blood bank.

## Key features

- User registration and secure login
- Universal user account: donor and requester capabilities
- Blood request creation for self, family, or friends
- Blood group and location-based donor matching
- Donor availability management
- Donor response coordination
- Admin request verification
- Blood-bank partner module
- Remote donor-to-nearest-blood-bank assignment
- Donation verification records
- LifeToken wallet and community tiers
- Privacy-conscious contact sharing
- Admin dashboard and partner dashboard

## Safety disclaimer

LifeLink is a coordination platform only. Donors must donate only at authorized blood banks or approved donation camps. Donor eligibility, medical screening, blood collection, testing, storage, compatibility checks, component processing, cold-chain handling, blood transport, and issue of blood are handled solely by authorized healthcare professionals and blood banks.

## Tech stack

- Frontend: React + Vite
- Backend: Node.js + Express.js
- Database: MongoDB Atlas
- Authentication: JWT + bcrypt
- API testing: Postman
- Deployment: Vercel + Render/Railway
